# The same empty room as tests/mods/test_autoequip, minus the item grant. It is a separate mod
# rather than a second map in that one because a row that loads test_autoequip also loads its
# reward event, and then a swap row would be measuring two things at once.
#
# Nothing is on this map. No enemies, no loot, no NPCs, no hotspot. That is the point: the row
# that runs here presses EQUIPMENT_SWAP and the only thing in the world that can change is what
# the character is wearing.
#
# The one event exists solely to carry a sound, because SFX_MAP_EVENT is emitted by an event with
# a soundfx component and by nothing else (EventManager.cpp:1115). Every row in the corpus asserts
# map_event is non-zero; without this the canary would have to be exempted here, and a check with
# an exemption in it is a check on its way out.
