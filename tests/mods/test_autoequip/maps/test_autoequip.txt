# An empty room with one event in it. The room is deliberately featureless: this map exists to
# execute ONE branch (auto-equip inside MenuInventory::add), and anything else on it -- enemies,
# loot, NPCs, a second event -- would put other code between the grant and the digest and make a
# failure harder to read, not easier.
#
# The hotspot covers the whole interior INCLUDING the spawn tile, so the event fires on the first
# tick rather than when the player walks somewhere. That is on purpose and it is a limit worth
# stating: this row covers the grant and the auto-equip decision, NOT the walk-onto-a-hotspot
# path, which every other recording already exercises against the real campaign maps.
#
# repeat is off. A repeating grant would hand out a second shirt the tick after the first, the
# chest slot would already be full, getEquipSlotFromItem(ONLY_EMPTY_SLOTS) would return -1 and
# the surplus would pile up in the carried area -- which is a different branch wearing this
# branch's clothes.
